# i18n

Cookie `DX_LOCALE` only — no `[locale]` segment, no locale middleware.

`lib/i18n/config.ts` · `request.ts` · `actions.ts` (`setLocale`) · `messages/{vi,en}.json`

Default `vi`, second `en`. **Same keys in both files** every change.

Namespaces now: `App`, `Home` ([baseline](baseline.md)). Add per record/shell (e.g. `Bugs`, `Workspace`).

`useTranslations("Namespace")` on client screens. E2E: [testing](testing.md).
